# My LibriVox Box

Browse, sort and sample free [LibriVox](https://librivox.org) audiobooks. Single-file web app in the Stack Tracker style.

- Sort by newest, oldest, title, author, length, or popularity (downloads, trending, ratings via the Internet Archive)
- Filter by length, language and genre; search titles and authors
- Sample any section, save books, and download zips, torrents or individual MP3s

Open: https://my-librivox-box.github.io/My-LibriVox-Box/
